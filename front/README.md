
## Description

JnpSmartRequestFront, est un l'interface front-end conçue pour la gestion des
des demandes (requetes) à l'interne de JNP
Cette interface communique avec à la fois avec l'API en NestJS,
un module Odooo et une Intélligence Artificielle

Il est conçu avec du NuxtJS , le framework de Vue.JS

## Technologie utilisées:
__VueJs
__NuxtJS
__Axios
__ShadCn Ui
__TailWindCss
__Bootstrap

## Demmarage du projet

```bash
# development
$ npm run start

$ npm run start:dev

# production mode
$ npm run start:prod
```
