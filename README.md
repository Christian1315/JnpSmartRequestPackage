
## Description

JnpSmartRequestPackage, est un package(melange de l'api et du front) de l' application intelligente JnpSmartRequest, conçue pour la gestion des
des demandes (requetes) à l'interne de JNP
Le front(fait en NuxtJS) & le l'api(fait en NestJS) communique,t avec à la fois avec l'API en NestJS ,
un module Odooo et une Intélligence Artificielle.
L'api leur sert de pond

Il est conçu avec du NuxtJS , le framework de Vue.JS

## Technologie utilisées:
__NodeJS
__NestJS
__Prisma
__VueJs
__NuxtJS
__Axios
__ShadCn Ui
__TailWindCss
__Bootstrap
